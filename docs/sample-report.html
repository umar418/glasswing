Activity

This version does not read activity logs, so it cannot tell you what your AI tools actually opened or ran. It reports what they are able to do.

Connections Glasswing cannot see

These live on each provider's own servers. Check them by hand:

  • Google Account — Apps and services with access to your Google account: https://myaccount.google.com/connections
  • Microsoft Account — Apps and services with access to your Microsoft account: https://account.live.com/consent/Manage
  • GitHub — Authorized OAuth apps: https://github.com/settings/applications
  • GitHub — Installed GitHub Apps: https://github.com/settings/installations
  • Slack — Apps installed in your workspace: https://slack.com/apps/manage
  • Claude — Connectors (Gmail, Drive, calendars and other connected apps): https://claude.ai/customize/connectors
  • ChatGPT — Connected apps (formerly called connectors): In ChatGPT, open Settings and choose Apps.
  • Gemini — Connected apps: https://gemini.google.com/apps

What this scan could not see

  • Connectors that run on a provider's own servers (for example Gmail or Drive connected inside claude.ai, ChatGPT or Gemini). Use the checklist in this report.
  • MCP servers bundled inside Claude Code plugins and Claude Desktop extensions.
  • What your AI tools actually did. This version reads settings only; it does not read activity logs or chat history.
  • The contents of your files. Glasswing looks at AI tool settings, never at your documents.
  • Organisation-managed settings pushed by an administrator through device management.
  • Any AI app that is not listed under 'Apps checked', and project folders outside the locations it searched.
  • What an online (remote) server can do once connected. Glasswing sees the address, not the service behind it.
